🍪 DL-40: Segregated Cookie Consent UI - Test Suite

Acceptance Criteria

✓ Criterion 1: Cookie Segregation Display

User can see cookies clearly segregated into "Necessary" and "Non-Necessary" sections with visual distinction.

✓ Criterion 2: Required Cookies Section

Necessary cookies section is marked as required and cannot be disabled, with examples: PHPSESSID, csrftoken, sessionid

✓ Criterion 3: Optional Cookies Section

Non-necessary cookies are displayed as separate toggleable options for Performance and Preferences with clear descriptions and examples.

✓ Criterion 4: Preference Enforcement

System enforces user choices and only sets cookies the user has consented to.

✓ Criterion 5: Cookie Cleanup

When user revokes consent for a category, existing cookies from that category are immediately deleted.
